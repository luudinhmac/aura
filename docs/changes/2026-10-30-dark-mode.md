# Dark mode — 2026-10-30

## Objective

Add a persistent dark interface for the Aura Talent application while retaining the brand and semantic status colors.

## Implementation

- Added a light/dark toggle to the global Navbar.
- Persisted the user choice in `localStorage` under `aura_theme`.
- Falls back to the operating-system preference when no choice is saved.
- Added shared dark theme overrides for application surfaces, neutral text, borders, inputs, and scrollbars.
- Preserved rose, amber, emerald, indigo, and sky colors used for branding and statuses.
- Fixed contrast caused by transparent neutral backgrounds: Navbar and table headers now receive dark surfaces before neutral text overrides are applied.
